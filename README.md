# NASA Exoplanet Data Analysis

## Overview
Exploratory data analysis of NASA's exoplanet dataset using Python to investigate planetary characteristics, discovery methods, and orbital properties.

## Technologies
Python, Pandas, Matplotlib, Seaborn, hvPlot, Plotly, Jupyter Notebook.

## Key Findings
- Planetary mass and radius exhibit positively skewed distributions.
- Short-orbital-period planets are heavily represented in the dataset.
- Several host stars have multiple known planets, including TRAPPIST-1.

## Dataset
NASA Exoplanet Archive. The analysis builds on a structured learning project; original instructional materials and starter code should be acknowledged where applicable.
